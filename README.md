**Yewb Web**: is a small web project of static website. I experiment there with different components of web. It has basics UI components, interactive layouts and responsive version.

## 🎯 Goals:

- Improve my skills in modern web development
- Build something that doesn't require big CMS
- Build simple and responsive (mobile friendly) interface, so later I can extend into larger application
- Later will be interesting to see how old version of page look like and how newer version of page will be


🌐 **Live demo:** https://jadzia-0.github.io/Yewb-web/  
📁 **Repository:** https://github.com/jadzia-0/Yewb-web

---

## 🚀 Features

- Minimal, clean UI layout  
- Responsive page structure  
- Basic navigation and component styling  
- Lightweight frontend without frameworks  
- GitHub Pages deployment

This project is intentionally simple at the beginning — it serves as a base you can build on and transform into a full application or portfolio piece.

---

## 🧰 Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**  
- **GitHub Pages** for deployment
[There's also piece of node.js, but works only 'locally' for this moment]

---

## 🎯 Purpose of the Project

The main objectives of this project are:

- Practicing web-development fundamentals  
- Improving clean UI design and layout organization
- Building a visible portfolio project to showcase on LinkedIn/GitHub  
- Preparing a base for further development (ex: dashboard, blog, AI tools, portfolio site, etc.)
